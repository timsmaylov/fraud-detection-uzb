# Fraud Detection Uzbekistan

Модель, которая оценивает вероятность мошенничества по карточной транзакции, и Streamlit-приложение для проверки транзакций и просмотра статистики. Дипломный проект, 2025.

## Данные

`fraud_project/data.csv`: 10 000 транзакций по городам Узбекистана и нескольким зарубежным, 3,95% из них мошеннические. Признаки: сумма в UZS и USD, категория магазина, тип операции, устройство, город, онлайн или офлайн, иностранная или нет.

## Модель

RandomForest (100 деревьев, `class_weight='balanced'`), отложенная выборка 20%:

| Метрика | Значение |
|---|---|
| ROC-AUC | 0.82 |
| Precision (fraud) | 0.50 |
| Recall (fraud) | 0.51 |

Модель находит примерно половину мошеннических операций, и примерно половина её срабатываний верна. Для учебного проекта это нормальная отправная точка, но не готовая антифрод-система.

## Запуск

```bash
cd fraud_project
pip install -r requirements.txt
python train_model.py     # переобучить модель (необязательно, готовая уже лежит в репозитории)
streamlit run app.py
```

Курс доллара приложение берёт с сайта ЦБ Узбекистана, а если сайт недоступен, подставляет 12 500 UZS.
