# Fraud Detection Uzbekistan — Project Bundle

В этой папке собраны все необходимые файлы для запуска и демонстрации модели детекции мошенничества:

## Состав
- `app.py` — Streamlit-приложение для проверки транзакций и просмотра статистики.
- `train_model.py` — скрипт для обучения модели (использует data.csv).
- `data.csv` — пример датасета (если не хотите делиться — уберите этот файл).
- `fraud_model.pkl` — обученная модель.
- `scaler.pkl` — scaler для числовых признаков.
- `cat_encoders.pkl` — словари кодирования категориальных признаков.
- `requirements.txt` — зависимости для запуска проекта.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   streamlit run app.py
   ```

---

**Если хотите поделиться только интерфейсом — уберите data.csv из этой папки.**
